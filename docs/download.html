balance Onestà sui numeri

Launcher da solo: ~150–250 MB RAM, CPU trascurabile a riposo. Footprint minimo, è il punto di forza.

Streaming: apre il TUO browser default → requisiti = quelli del browser per video 1080p/4K. Vecchio PC + 4K Netflix = scatti, colpa del browser non del launcher.

Giochi/emulatori: lanciati come processi separati → requisiti dettati dal gioco/emu, il launcher non aggiunge overhead mentre girano.

Sidecar Node: parte solo quando serve, auto-exit dopo 60s idle.

No GPU dedicata necessaria per il launcher in sé — la UI è web semplice. Serve per ciò che lanci.

Sintesi: qualsiasi PC capace di far girare i tuoi giochi/streaming fa girare il launcher senza problemi. Non è lui il collo di bottiglia. Minimo pratico: PC Windows 10 funzionante + un controller. Alpha = non testato su hardware esotico/ARM.
