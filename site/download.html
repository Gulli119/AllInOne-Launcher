Installazione e Persistenza

Esegui l'installer scaricato. Il programma verrà installato in %APPDATA%\AllInOneUI per garantire permessi ottimali e la persistenza dei dati senza necessità di permessi di amministratore.

2

Avvio Automatico

Per un'esperienza ottimale, abilita l'avvio automatico all'accensione del PC navigando in Impostazioni > Sistema. L'interfaccia si avvierà in modalità kiosk.

3

Risoluzione Problemi

In caso di problemi, verifica i file di log in %APPDATA%\AllInOneUI\logs o consulta la sezione di troubleshooting nella repository GitHub per soluzioni comuni.
